# HU-04 -- PORTAFOLIO, PROGRAMA Y PROYECTO

**Objetivo:** Definir el portafolio, programas y proyectos, y ubicar
allí el proyecto propio.

## Registro

  -----------------------------------------------------------------------
  Nivel                   Nombre                  Relación
  ----------------------- ----------------------- -----------------------
  Portafolio              Mejoramiento y          Nivel superior
                          transformación de       
                          procesos de producción  

  Programa                Optimización de         Pertenece al portafolio
                          producción de panadería 

  Proyecto                Sistema de monitoreo    Pertenece al programa
                          del proceso de          
                          fabricación de pan      
                          trenza                  
  -----------------------------------------------------------------------

## Estructura de gestión

**Portafolio:** Mejoramiento y transformación de procesos de producción

↓

**Programa:** Optimización de producción de panadería

↓

**Proyecto:** Sistema de monitoreo del proceso de fabricación de pan
trenza

## Registro dentro de la aplicación

La aplicación permitirá registrar el portafolio, el programa y el
proyecto, estableciendo la relación jerárquica **Portafolio → Programa →
Proyecto**.

  -----------------------------------------------------------------------
  Campo                               Valor registrado
  ----------------------------------- -----------------------------------
  Portafolio                          Mejoramiento y transformación de
                                      procesos de producción

  Programa                            Optimización de producción de
                                      panadería

  Proyecto                            Sistema de monitoreo del proceso de
                                      fabricación de pan trenza
  -----------------------------------------------------------------------
