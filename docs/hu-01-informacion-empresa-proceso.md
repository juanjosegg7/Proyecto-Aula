## 4. ¿Qué va a monitorear la aplicación?

La aplicación no monitoreará físicamente cada máquina o etapa en tiempo real. Registrará los datos de producción de cada lote y utilizará esta información para calcular indicadores que permitan conocer el comportamiento del proceso.

| Dato monitoreado | Uso |
|---|---|
| Cantidad producida | Conocer cuántas unidades se fabricaron en cada lote. |
| Cantidad defectuosa | Identificar unidades que no cumplen con los criterios establecidos. |
| Cantidad aprobada | Conocer las unidades que cumplen los criterios de calidad. |
| Tiempo de producción | Medir cuánto tiempo tomó producir el lote. |
| Materia prima utilizada | Registrar la cantidad de materia prima empleada. |
| Materia prima desperdiciada | Controlar la cantidad de material que se desperdicia. |
| Porcentaje de defectos | Medir la proporción de unidades defectuosas. |
| Porcentaje de producción aprobada | Medir la proporción de unidades aprobadas. |
| Productividad | Relacionar la producción con el tiempo empleado. |
| Porcentaje de desperdicio | Medir el desperdicio respecto a la materia prima utilizada. |
