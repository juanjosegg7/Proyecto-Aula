Aún no hay datos para el tablero

Cargue un archivo de producción (Excel o CSV) o registre lotes manualmente. El tablero se genera automáticamente.

Metas del tablero

Las metas son supuestos editables hasta que la panadería defina las suyas (ver fichas técnicas). Se guardan en este navegador.

Metas del tablero OEE

Valores de referencia editables: OEE de clase mundial 85 % (A 90 %, R 95 %, Q 99,9 %). Se guardan en este navegador.

Cargar datos de producción

El archivo se procesa en su navegador; no se envía a ningún servidor. Las columnas se reconocen por su nombre (p. ej. «Panes», «Panes producidos», «Defectuosos», «Tiempo total», «Material kg», «Desperdicio kg» o «Desperdicio %»). Si alguna no se reconoce, puede asignarla abajo.

También acepta un libro relacional (hojas de producción, paros, productos, turnos, motivos de paro, máquinas y operadores): en ese caso genera el tablero OEE con disponibilidad, rendimiento, calidad, Pareto de paros y productividad de mano de obra; y SLA y % no vendido si el libro trae pedidos o ventas.
